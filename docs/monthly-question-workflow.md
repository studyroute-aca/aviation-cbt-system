# 毎月の問題作成ワークフロー

1. AIへ、`templates/question-generation-template.json` の形式・対象分野・問題数を指定して作成を依頼する。
2. JSONを年月フォルダ（例：`src/data/exams/2026-11/`）へ保存する。IDは `Q-YYYY-MM-001` とし、同月内で重複させない。
3. 問題文、選択肢が4つあること、正解IDの存在、解説・配点・年月を検証する。問題IDの重複も確認する。
4. 生成直後は必ず `reviewStatus: "draft"`、`status: "unpublished"` とする。
5. 人間が計算、正答、表現、重複、難易度、解説を確認し、問題を `review`、確認完了後に `approved` へ更新する。
6. approvedの問題だけを選択して `published` にする。draft/reviewやunpublishedの問題は受験画面へ出さない。
7. 翌月は新しい年月・examIdのセットを追加し、試験設定から参照先を切り替える。過去セットは削除せず保持する。
8. AIの誤りを防ぐため、公開前に複数人で正答と解説を確認し、必要に応じて計算・出典を再確認する。

本番ではJSONの検証と公開切替をCIまたは管理画面で行い、クライアントへ正答を配信しないサーバー構成へ移行してください。
